# iFocus Fitness live coach preview

Preview only. This is not the live app at dtime2026.github.io/ifocus-fitness-demo and nothing there links here.

Full-screen 3D coach view using the approved rigged Meshy coaches (Avery, Ellis, Maren, Ione):
- Squat, bicep curl and push-up animations (Meshy presets on each coach's own rig)
- Live rep counter driven by the animation cycle
- Text cues on screen plus spoken cues (browser speech, en-GB) with a voice toggle
- Tap the coach for a boost (cue, floor pulse, jumping jacks when idle)
- Coach switcher, `?coach=avery|ellis|maren|ione`

Built with three.js r169 (MIT). Models: EXT_meshopt_compression, KHR_mesh_quantization, WebP textures.
